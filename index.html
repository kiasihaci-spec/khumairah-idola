Panduan Catatan Wajib

Draft Isian Buku Catatan Informatika XII

Salinlah poin-poin terstruktur di bawah ini ke dalam buku catatan fisik Informatika Anda sesuai ketentuan guru.

1 Ide dan Tujuan Website

Ide: Membuat website portofolio interaktif untuk idola musik global, yaitu Jennie Kim (BLACKPINK).

Tujuan: Menyajikan informasi profil, latar belakang pendidikan, perjalanan karir, keahlian, serta galeri foto Jennie secara terstruktur sekaligus mempraktikkan alur kerja pengembangan web menggunakan Git, GitHub, dan GitHub Pages.

2 Struktur Proyek HTML & CSS

• Folder Utama: portofolio-jennie/

• Folder Aset: assets/img/ (Menyimpan seluruh foto portofolio agar rapi).

• Folder Styling: css/style.css (Menggunakan CSS Native External).

• Menu File Terpisah: index.html (Beranda Utama) dan profile.html (Halaman Detail Profil & Galeri).

3 Proses Git & GitHub (Langkah-Langkah Komando)

A. Inisialisasi & Penghubungan ke GitHub Repository:
  1. git init
  2. git add .
  3. git commit -m "Initial commit - Portofolio Jennie Kim"
  4. git branch -M main
  5. git remote add origin https://github.com/USERNAME/portofolio-jennie.git
  6. git push -u origin main
B. Mengaktifkan GitHub Pages:

Masuk ke Repo GitHub → Tab Settings → Menu Pages → Pada bagian Source pilih branch main → Klik Save. Tunggu URL publik terbit.

C. Proses Edit File & Push Ulang:
  1. git add .
  2. git commit -m "Update deskripsi biodata dan galeri"
  3. git push

4 Penjelasan Konsep Push & Pull

PUSH

Proses mengirimkan data perubahan komit dari server lokal (komputer/laptop) ke repository online di cloud (GitHub).

PULL

Proses mengambil (fetch & merge) data/perubahan terbaru dari remote repository di cloud (GitHub) ke server lokal (komputer/laptop).

5 Kendala, Solusi, dan Kesimpulan

Kendala: Jalur (path) gambar tidak terbaca saat diakses melalui GitHub Pages.

Solusi: Memastikan penulisan folder aset bersifat relatif (misal: assets/img/jennie.jpg) dan memperhatikan perbedaan huruf kapital (case-sensitive) pada Linux/GitHub server.

Kesimpulan: Melalui tugas ini, saya tidak hanya memahami sintaks dasar HTML dan CSS Native, tetapi juga menguasai Version Control System (Git) untuk memublikasikan website secara aktual menggunakan GitHub Pages.
